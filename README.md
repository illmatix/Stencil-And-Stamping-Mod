# Stencil & Stamping Mod for Vintage Story

Cut stencil patterns, mix inks from natural pigments, and stamp decorative designs onto walls, floors, and surfaces throughout your builds.

## Features

- **Stencil crafting** — cut patterns into leather or metal sheets using a knife on a cutting board
- **Natural ink system** — grind pigments and mix with binders to create colored inks
- **Stamp tool** — combine a handle with a stencil to create a reusable stamp
- **Surface stamping** — apply patterns to block faces (stone, plaster, wood, clay)
- **Pattern variety** — geometric borders, nature motifs, symbols, and decorative marks
- **Durability & wear** — stamps degrade with use; metal stencils last longer than leather

## Quick Start

1. **Craft a cutting board** — plank + knife in the grid
2. **Cut a stencil** — place leather or metal sheet on the cutting board, select a pattern
3. **Mix ink** — grind pigments (charcoal, berries, clay, flowers) and combine with a binder (fat, resin)
4. **Assemble a stamp** — combine stencil + stick handle in the grid
5. **Stamp!** — hold stamp in main hand, ink in offhand, right-click a surface

## Installation

Drop the `StencilAndStamping` folder into your `VintagestoryData/Mods/` directory.

## Configuration

Pattern sets and ink recipes can be toggled via `ModConfig/StencilAndStampingConfig.json`. See [docs/configuration.md](docs/configuration.md) for details.
